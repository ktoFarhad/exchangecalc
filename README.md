# ExchangeCalc

ExchangeCalc — это простой, удобный сайт для конвертации валют, созданный с использованием HTML, CSS и JavaScript. Он позволяет пользователям конвертировать между различными валютами, используя актуальные обменные курсы.

## Особенности

- Конвертация валют с актуальными обменными курсами
- Просмотр текущих курсов обмена для нескольких валют
- Адаптивный дизайн для настольных и мобильных устройств
- Простой, чистый интерфейс с сине-зеленой цветовой схемой

## Начало работы

1. Клонируйте или скачайте этот репозиторий
2. Откройте `index.html` в вашем веб-браузере

Не требуется процесс сборки или установки, так как это чистый проект HTML/CSS/JavaScript.

## Использование API

Этот проект использует [ExchangeRate-API](https://www.exchangerate-api.com/) для получения текущих курсов валют. Используется бесплатная версия, которая позволяет делать до 1 500 запросов API в месяц.

API вызывается в следующем формате:
\`\`\`
https://open.er-api.com/v6/latest/USD
\`\`\`

Где `USD` — базовая валюта. Ответ включает курсы обмена для всех доступных валют относительно базовой валюты.
